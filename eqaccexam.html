等加速運動測驗

測驗方式

每題會出現一張「速度－時間（v-t）圖」，請依圖判斷物體的運動狀態，選好所有選項後按「送出答案」。

  • 全部答對 +10 分，有任一項答錯 −5 分（最低 0 分）。
  • 累積到 100 分即完成測驗，會記錄作答題數與用時。
  • 規定向前為正方向。

看圖小提示

  • 運動方向：看速度的正負。圖線在 0 以上（v > 0）為向前，在 0 以下（v < 0）為向後，一直在 0 線上則是靜止。
  • 加速度：看圖線的斜率。往右上升為大於 0，水平為等於 0，往右下降為小於 0。
  • 合力方向：由牛頓第二運動定律 F = ma，合力方向與加速度方向相同；加速度為 0 時合力為零。
  • 注意：判斷加速度的正負要看斜率，不能只看物體變快或變慢！
